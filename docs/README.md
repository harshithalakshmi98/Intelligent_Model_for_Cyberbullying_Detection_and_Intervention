# Documentation

Project documentation is grouped by purpose.

## Structure

```
docs/
├── research/
│   └── ResearchReport.md          # Full research report (markdown)
├── guides/
│   ├── practical-approach-implementation-guide.md
│   ├── practical-approach-simplified.md
│   ├── dataset-overlap-analysis.md
│   ├── dissertation-key-factors-from-papers.md
│   └── additional-datasets-for-validation.md
├── reports/
│   └── FINAL_README_PHASE1_3.md   # Final implementation summary (Phases 1-4)
└── reference-materials/
    ├── *.pdf, *.docx              # Journal templates, examples, declaration
    └── Overview of Repo.png

MP/ (project root)                 # HWU dissertation structure, length, submission notes
```

## Where to start

| Goal | Read |
|------|------|
| Understand the research | `research/ResearchReport.md` |
| Implement the model step-by-step | `guides/practical-approach-implementation-guide.md` |
| Quick overview without jargon | `guides/practical-approach-simplified.md` |
| Avoid data leakage in validation | `guides/dataset-overlap-analysis.md` |
| Final implementation summary | `reports/FINAL_README_PHASE1_3.md` |
| Track implementation tasks | `../PROJECT_CHECKLIST.md` (project root) |
| Dissertation formatting (HWU) | `../MP/` (project root) |

Implementation code lives in the project root (`data/`, `features/`, `models/`, etc.), not under `docs/`.
